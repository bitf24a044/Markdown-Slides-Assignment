Markdown Slides Assignment

Files:
- index.html: application structure
- style.css: page design
- script.js: slide creation, editing, preview, saving and presentation

IMPORTANT:
Keep all three files in the same folder. Open index.html from the extracted folder.
If you want to publish the project, upload all three files to the same GitHub repository
and enable GitHub Pages. The site should then be opened from its GitHub Pages URL.

How to use:
1. Edit Markdown in the left box.
2. Use --- on a separate line between slides.
3. Preview changes on the right.
4. Click Save Slides.
5. Click Present Slides to present.
